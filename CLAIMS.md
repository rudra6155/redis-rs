# CLAIMS

The ledger behind the README. Every `[C#]` tag in [README.md](README.md) is a row here:
**claim | artifact path | command that regenerates it | status**.

* **VERIFIED** = I ran the command in the session that produced the artifact, and the artifact is committed.
* **PENDING** = not verifiable from a committed artifact yet; the README text says so next to the claim.
* **BLOCKED** = could not run (e.g. no Docker for the benchmark). None are blocked: the reference `redis:7`
  was started, so there is no `results/BENCH_BLOCKED.txt`.

All commands run from the repo root. "container" = the Linux dev container on Docker Desktop (the author's host
had no Rust toolchain); the oracle there is a sibling `redis:7` via `ORACLE_ADDR`, or the tests' own `docker run`
(see C26). Oracle = `redis:7`, measured 7.4.12.
